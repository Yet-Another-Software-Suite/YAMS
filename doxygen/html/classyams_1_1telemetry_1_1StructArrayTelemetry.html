Detailed Description

template<typename T, typename F>
class yams::telemetry::StructArrayTelemetry< T, F >

NT4 pub/sub wrapper for a struct-encoded array telemetry field.

Mirrors StructTelemetry, but publishes an array of struct-serializable values instead of a single value.

Template Parameters
TStruct-serializable array element type.
FEnum type identifying which field this telemetry entry represents.
