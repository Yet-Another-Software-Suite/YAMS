Detailed Description

SmartMotorController implementation for the FIRST A301 smart motor, using REVLib 2027.

The A301 has no closed loop gains, so the closed loop controller runs on the SystemCore and commands the A301 with voltage. It also has no current limits, ramp rates, voltage compensation or follower mode, and configuring them throws a SmartMotorControllerConfigurationException.

The gearing given to WithMotorGearing is from the A301's rotor to the mechanism: usually the gearbox attached to the A301, and any gearing after it. The A301 has one motor, YMotors::A301().

REVLib does not simulate the A301, so in simulation the wrapper drives a DCMotorSim.

External encoder: the A301's own absolute encoder, on its output shaft, used by giving the first::a301::A301* itself to WithExternalEncoder. Its gearing, given to WithExternalEncoderGearing, is from the output shaft to the mechanism. Its zero offset, inversion and wrapping range are applied by the wrapper; without WithWrapping it reads [0, 1) rotations of the encoder.

Example usage (inside a subsystem constructor)

using namespace yams::motorcontrollers;
using namespace yams::motorcontrollers::local;
// Declare as subsystem members:
// first::a301::A301 m_a301{wpi::CANPort::CAN_S0, 3};
// SmartMotorControllerConfig m_cfg;
// std::optional<A301Wrapper> m_smc;
// The A301 has its 64:1 gearbox.
m_cfg.WithSubsystem(this)
.WithMotorGearing(yams::gearing::MechanismGearing{64.0})
.WithFeedback(1.0, 0.0, 0.0)
.WithMotorInverted(false)
.WithExternalEncoder(&m_a301)
.WithUseExternalFeedbackEncoder(true)
.WithClosedLoopMode()
.WithTelemetry("ArmMotor", SmartMotorControllerConfig::TelemetryVerbosity::HIGH);
m_smc.emplace(&m_a301, &m_cfg);
