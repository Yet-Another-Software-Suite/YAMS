Detailed Description

SmartMotorController implementation for REV SPARK Max and SPARK Flex motor controllers.

Supports both SPARK Max and SPARK Flex hardware via a common internal interface. Wraps REV SparkBase, SparkClosedLoopController, and encoder objects to satisfy the SmartMotorController contract.

The SPARK runs in the raw units of its feedback sensor (rotations and RPM of the motor's encoder, or of the external encoder when it is used for feedback); no conversion factors are configured. Gains, setpoints, MAXMotion constraints, tolerances and soft limits are scaled from YAMS mechanism units by the mechanism-to-feedback-sensor ratio.

Supported external encoders (WithExternalEncoder): rev::spark::SparkAbsoluteEncoder*, rev::spark::SparkMaxAlternateEncoder* / rev::spark::SparkFlexExternalEncoder* (quadrature), and rev::detached::DetachedEncoder* / rev::detached::SplineEncoder* (read over CAN).

External encoder discontinuity point (absolute and detached encoders): 0.5 rotations reports [-0.5, 0.5), 1 rotation (the default) reports [0, 1).

Example usage SPARK Max (inside a subsystem constructor)

using namespace yams::motorcontrollers;
using namespace yams::motorcontrollers::local;
using namespace yams::gearing;
using Cfg = SmartMotorControllerConfig;
// Declare as subsystem members:
// rev::spark::SparkMax m_sparkMax{3,
rev::spark::SparkLowLevel::MotorType::kBrushless};
// std::optional<SparkWrapper> m_smc;
SmartMotorControllerConfig cfg;
cfg.WithSubsystem(this)
.WithFeedback(1.0, 0.0, 0.0)
.WithMechanismCircumference(0.25_in, 22)
.WithMotorGearing(MechanismGearing{GearBox::FromReductionStages({3.0, 4.0})})
.WithZeroPower(Cfg::MotorMode::BRAKE)
.WithSupplyCurrentLimit(40.0_A)
.WithMotorInverted(false)
.WithFeedforward(wpi::math::ElevatorFeedforward{
0.0_V, 0.0_V, wpi::units::unit_t<wpi::math::ElevatorFeedforward::kv_unit>{0.0},
wpi::units::unit_t<wpi::math::ElevatorFeedforward::ka_unit>{0.0}})
.WithClosedLoopMode()
.WithTelemetry("ElevatorMotor", Cfg::TelemetryVerbosity::HIGH);
m_smc.emplace(&m_sparkMax, wpi::math::DCMotor::NEO(1), &cfg);
