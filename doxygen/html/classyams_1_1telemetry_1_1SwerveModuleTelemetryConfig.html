Detailed Description

Swerve module telemetry configuration.

Use this builder to select exactly which fields are published to NetworkTables and/or DataLog. Every field is disabled by default; call the individual With*() methods to opt in, or use WithTelemetryVerbosity() to enable a predefined set.

Example

SwerveModuleTelemetryConfig telemetryCfg =
SwerveModuleTelemetryConfig()
.WithTelemetryVerbosity(TelemetryVerbosity::HIGH)
.WithAbsoluteEncoder()
.WithState()
.WithoutNetworkTables()
.WithDataLogName("swerve/modules/frontleft");
