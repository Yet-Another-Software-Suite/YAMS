Detailed Description

template<typename F>
class yams::telemetry::BooleanTelemetry< F >

NT4 pub/sub wrapper for a single boolean-valued telemetry field.

Generic over the enum type F identifying which field this entry represents, so the same wrapper can be reused across unrelated telemetry coordinators (e.g. SmartMotorControllerTelemetry uses BooleanTelemetry<BooleanTelemetryField>, while SwerveDriveTelemetry uses its own field enum).

Template Parameters
FEnum type identifying which field this telemetry entry represents.
