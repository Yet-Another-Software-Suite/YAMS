Detailed Description

template<typename F>
class yams::telemetry::StringTelemetry< F >

NT4 pub/sub wrapper for a single string-valued telemetry field, such as the name of the mode a mechanism is in.

Template Parameters
FEnum type identifying which field this telemetry entry represents.
