Detailed Description

Configuration class for an Elevator mechanism.

Uses a fluent builder pattern; all With* methods return *this for chaining.

template<typename... Heights>
requires (std::convertible_to<Heights, wpi::units::meter_t> && ...)
ElevatorConfig & yams::mechanisms::config::ElevatorConfig::WithStages ( Heights... stageHeights)
inline

Set the elevator's moving stages, for the pose of each stage from Elevator::GetCascadePose3d() or Elevator::GetContinuousPose3d(bool).

The stage heights must add up to the elevator's maximum height: the Elevator throws if they do not. Without a minimum and maximum height, the elevator's height is from 0 to the stage heights' total.

Parameters
stageHeightsHow far each moving stage travels relative to the stage below it, from the stage nearest the fixed stage to the carriage, which is the last. One for each stage that moves, such as WithStages(0.6_m, 0.6_m, 0.5_m).
Returns
*this for chaining.
Exceptions
std::invalid_argumentif no height is given, or a height is not positive.
